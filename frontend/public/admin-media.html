Checking session…

Note: this backend does not accept real file uploads — there's no multipart handling anywhere. "Recording" media just registers a URL (something already reachable, e.g. a file already placed under /media/...) as a database row. Think of it as a media registry, not an upload form.

1. Record New Media

Creates a media row, and optionally links + orders it on a catalog item in the same call if you provide a cid.


2. Link Existing Media to a Catalog Item

3. Set Primary Image

4. Unlink Media from a Catalog Item

Removes the link only — the media record itself still exists and can be relinked or deleted separately.

5. Delete Media Record

Hard-deletes the media row entirely (not just one link) — it disappears from every catalog item it was linked to.
